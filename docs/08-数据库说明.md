# 08 数据库说明

## SQL 文件

数据库脚本统一放在：

```text
docs/database/
```

| 文件 | 说明 |
| --- | --- |
| `zhihuitong.sql` | 当前主库结构和基础数据 |
| `auth_schema.sql` | 认证权限相关结构 |
| `data_scope_migration.sql` | 数据权限迁移 |
| `ai_decision_support_migration.sql` | AI 排产/质检分析相关迁移 |
| `20260830_device_capability_menu.sql` | 设备能力管理菜单和角色权限迁移 |

## 数据库初始化

```bash
mysql -uroot -p -e "CREATE DATABASE zhihuitong DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -uroot -p zhihuitong < docs/database/zhihuitong.sql
```

## 主要业务表

| 领域 | 主要表 | 说明 |
| --- | --- | --- |
| 系统权限 | `systemuser`、`systemrole`、`systemmenu`、`systemdept`、`systempost` | 用户、角色、菜单、部门、岗位 |
| 订单 | `orderinfo`、`orderitem`、`orderbatchlink` | 订单、明细、批次分配 |
| 批次 | `batchinfo` | 来料批次 |
| 工艺 | `processroute`、`processstep`、`routestep`、`machine`、`stepmachinecapability` | 路线、工序、设备、能力 |
| 排产 | `productionplan`、`planstep`、`processparameter` | 生产计划、工序计划、工艺参数 |
| 质检 | `qcrecord`、`inspectiondata`、`qcitem`、`qccamera` | 质检记录、附件、项目、摄像头 |
| 异常 | `exceptionrecord` | 异常、返工、关闭 |
| AI | `aischedulerecord` | AI 排产建议记录 |

表名以实际 SQL 为准。当前项目 MyBatis-Plus 配置了 `table-underline: false`，因此命名风格不要随意切换。

## 关键关系

```text
orderinfo 1 -> n orderitem
orderitem 1 -> n orderbatchlink
batchinfo 1 -> n productionplan
processroute 1 -> n routestep
productionplan 1 -> n planstep
planstep 1 -> n qcrecord
planstep 1 -> n exceptionrecord
qcrecord 1 -> n inspectiondata
```

设备删除约束：

- `machine` 被 `stepmachinecapability` 引用时不能删除；
- `machine` 被 `planstep` 引用时不能删除；
- 未被引用的设备可以通过 `DELETE /api/machines/{machineId}` 删除；
- 已投入业务使用的设备建议改为停用，保留历史计划和工艺关联。

## ID 规则

后端使用 MyBatis-Plus `assign_id` 生成雪花 ID。前端展示时要用短号格式化工具，但数据库、接口、路由参数必须保留原始 ID。

## 数据库变更规范

1. 新增字段或表时，同步修改：
   - SQL 脚本；
   - Entity；
   - DTO/VO；
   - Mapper/Service；
   - 前端类型。
2. 不要只改本地数据库而不提交迁移脚本。
3. 脚本命名建议：

```text
docs/database/yyyyMMdd_feature_name.sql
```

4. 生产库执行前必须先备份。
