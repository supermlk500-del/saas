# 测试指南

更新时间：2026-06-20

## 1. 必跑命令

```powershell
mvn -f backend/pom.xml test
Set-Location frontend
npm run build
```

当前完整后端测试基线：29 个测试，0 失败，0 错误。后续测试增加后应更新此处。

前端构建同时执行 `vue-tsc` 和 Vite。Vite 大 chunk 警告是当前已知问题，不等于构建失败。

## 2. 后端测试重点

| 范围 | 当前覆盖 |
| --- | --- |
| 订单 | 服务逻辑、运行时表结构校验、Long ID 序列化 |

## 3. 登录与会话回归

必须验证：

- 登录按钮和 Enter 都能发起登录请求。
- 空用户名、空密码和空验证码由前端阻止。
- 错误验证码返回 400，验证码一次性消费。
- 错误密码返回 401，并在登录页显示错误。
- 登录成功后依次请求 `/auth/login`、`/auth/me` 并进入 `/dashboard`。
- 主动退出后旧 token 返回 401。
- 用户停用、管理员强退、本人改密和管理员重置密码后旧 token 立即失效。
- 登录审计字段过长或审计写入失败时，认证仍可正常完成。

## 4. 角色权限回归

对 7 个非管理员角色至少验证：

1. `/auth/me` 返回正确 `roleKey`、`permissions` 和 `menuKeys`。
2. 角色允许的查询接口返回 200。
3. `/system/user/list` 返回 403。
4. viewer 写操作返回 403。
5. 页面菜单与后端权限一致。
6. 测试账号在结束后物理清理，不能只做逻辑删除。

## 5. 看板回归

- 全部 8 个角色都能打开看板。
- `GET /api/dashboard/overview` 返回 200。
- 页面不再跨权限调用批次、质检、异常和计划列表接口。
- 聚合接口返回：待检批次、今日/昨日数量、本周/上周质检、最近质检、异常、计划。
- 非管理员直接访问未授权业务接口仍返回 403。
- 浏览器无错误弹窗和控制台错误。

## 6. 实时质检回归

使用 `qc_inspector` 验证页面初始化：

| 接口 | 期望 |
| --- | --- |
| `/api/plan-steps` | 200 |
| `/api/qc-items` | 200 |
| `/api/qc-records` | 200 |
| `/api/qc-cameras` | 200 |
| `PUT /api/plan-steps/{id}` | 403 |

还需验证：

- 浏览器摄像头授权和预览。
- 创建、连接和关闭实时检测会话。
- WebSocket 匿名握手失败，带 token 握手成功。
- 关键帧保存、结果图、检测框和质检记录一致。
- 匿名图片访问 401，带 token 图片访问 200 且 Content-Type 正确。

## 7. 页面与浏览器

至少检查：

- 桌面：1440×900 或更大。
- 移动端：390×844。
- 无横向溢出、文本遮挡和控件重叠。
- 路由守卫能把无菜单权限页面重定向到看板。
- 浏览器 Network 没有非预期 401/403/500。
- Console 没有运行时错误和 Vue 警告。

## 8. 测试数据规范

- 测试用户名使用明确前缀，例如 `it_`、`dashcheck_`。
- 不使用生产账号执行停用、改密、强退测试。
- 测试结束后清理用户、登录日志和 Redis 会话。
- 不在文档、日志或截图中保存完整 token、验证码或生产密码。

## 10. 已知限制

- 前端暂无 Vitest/Playwright 仓库脚本，浏览器回归目前需要手工或外部 Playwright 执行。
- 构建存在主 chunk 超过 500 KB 的警告。
- MyBatis-Plus 会提示关系表缺少单一 `@TableId`；这两张表应使用组合条件查询，不使用 ById 方法。
