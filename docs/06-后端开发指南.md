# 06 后端开发指南

## 技术栈

- Spring Boot 3.3
- Spring Security
- MyBatis-Plus
- MySQL
- Redis
- WebSocket
- ONNX Runtime
- OR-Tools

## 目录说明

```text
backend/src/main/java/com/zhihuitong
├── common/       # 通用返回、分页、异常、工具
├── config/       # 框架配置
├── security/     # 登录、JWT、权限、数据权限、会话
└── modules/      # 业务模块
```

业务模块内部通常按以下结构组织：

```text
controller/
dto/
entity/
mapper/
service/
vo/
```

## 新增后端功能流程

1. 确定模块归属，例如 `order`、`plan`、`quality`。
2. 新增或修改 `entity`，对应数据库表。
3. 新增 `dto` 用于请求参数。
4. 新增 `vo` 用于返回给前端。
5. 新增 `mapper` 访问数据库。
6. 在 `service` 写业务逻辑。
7. 在 `controller` 暴露接口。
8. 给接口加权限标识。
9. 补充前端 `api` 和页面调用。

## 返回格式

普通接口使用：

```text
AjaxResult
```

分页接口使用：

```text
TableDataInfo
```

异常应抛出业务异常或交给全局异常处理器，不要在 Controller 中拼散乱错误结构。

## MyBatis-Plus 约定

配置位置：

```text
backend/src/main/resources/application.yml
```

当前配置：

- `map-underscore-to-camel-case: false`
- `id-type: assign_id`
- `table-underline: false`

这意味着数据库字段和 Java 字段映射要格外注意，不能默认假设下划线自动转驼峰。

## 配置规范

敏感信息必须通过环境变量传入，不要写死在代码或配置文件里。

常用环境变量：

| 变量 | 说明 |
| --- | --- |
| `MYSQL_HOST` | MySQL 地址 |
| `MYSQL_PORT` | MySQL 端口 |
| `MYSQL_DATABASE` | 数据库名 |
| `MYSQL_USERNAME` | 数据库账号 |
| `MYSQL_PASSWORD` | 数据库密码 |
| `REDIS_HOST` | Redis 地址 |
| `REDIS_PASSWORD` | Redis 密码，可为空 |
| `JWT_SECRET` | JWT 密钥，至少 32 字节 |
| `DEEPSEEK_API_KEY` | DeepSeek Key |
| `AI_YOLO_MODEL_PATH` | ONNX 模型路径 |

## 质检推理

ONNX 模型由后端直接加载，不依赖独立 Python 服务。

核心类：

```text
modules/ai/service/OnnxYoloService.java
modules/quality/service/InspectionIntegrationService.java
modules/quality/service/QcStreamSessionService.java
```

## 排产建议

核心类：

```text
modules/ai/service/AiSchedulingService.java
modules/ai/service/DeepSeekExplanationService.java
```

排产计算应使用规则、算法和 OR-Tools，大模型只用于解释。
