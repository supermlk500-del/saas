# 02 快速启动

## 环境要求

| 依赖 | 建议版本 | 用途 |
| --- | --- | --- |
| JDK | 17 | 后端运行 |
| Maven | 3.8+ | 后端依赖与构建 |
| Node.js | 20.19+ 或 22.12+ | 前端运行 |
| MySQL | 8.x | 业务数据库 |
| Redis | 6+ / 7+ | 登录会话、验证码、在线状态 |

## 数据库初始化

创建数据库：

```sql
CREATE DATABASE zhihuitong DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

导入主脚本：

```bash
mysql -uroot -p zhihuitong < docs/database/zhihuitong.sql
```

如果是从旧库升级，再按需要执行：

```bash
mysql -uroot -p zhihuitong < docs/database/auth_schema.sql
mysql -uroot -p zhihuitong < docs/database/data_scope_migration.sql
mysql -uroot -p zhihuitong < docs/database/ai_decision_support_migration.sql
```

全新库通常直接导入 `zhihuitong.sql` 即可。

## Redis

本地可以直接启动一个 Redis。无密码时后端配置 `REDIS_PASSWORD` 留空即可；有密码时需要配置环境变量。

```bash
docker run -d --name zhihuitong-redis -p 6379:6379 redis:7-alpine
```

## 后端启动

进入后端目录：

```bash
cd backend
```

设置必要环境变量。Windows PowerShell 示例：

```powershell
$env:MYSQL_HOST="localhost"
$env:MYSQL_PORT="3306"
$env:MYSQL_DATABASE="zhihuitong"
$env:MYSQL_USERNAME="root"
$env:MYSQL_PASSWORD="你的数据库密码"
$env:REDIS_HOST="localhost"
$env:REDIS_PORT="6379"
$env:JWT_SECRET="change-this-development-secret-to-at-least-32-bytes"
$env:DEEPSEEK_API_KEY="你的 DeepSeek Key，可先留空"
$env:AI_YOLO_MODEL_PATH="D:/lhr/Desktop/saas/docs/best.onnx"
$env:INSPECTION_STORAGE_UPLOAD_ROOT="D:/lhr/Desktop/saas/photo/upload"
$env:INSPECTION_STORAGE_RESULT_ROOT="D:/lhr/Desktop/saas/photo/results"
mvn spring-boot:run
```

默认后端地址：

```text
http://localhost:8080
```

健康检查：

```text
http://localhost:8080/actuator/health
```

## 前端启动

进入前端目录：

```bash
cd frontend
npm install
npm run dev
```

默认前端地址：

```text
http://localhost:5173
```

前端通过 `/prod-api` 代理后端，配置位置：

```text
frontend/vite.config.ts
```

## 常见启动顺序

1. 启动 MySQL。
2. 导入数据库脚本。
3. 启动 Redis。
4. 启动后端。
5. 启动前端。
6. 浏览器访问 `http://localhost:5173`。

## 首次登录

账号和密码以导入的数据库数据为准。若验证码不显示，优先检查：

- 后端是否启动成功；
- Redis 是否可连接；
- `JWT_SECRET` 是否至少 32 字节；
- 前端 `/prod-api/auth/captcha` 是否代理到后端。
