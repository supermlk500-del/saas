# 02 核心业务测试用例

## 用例等级说明

| 等级 | 含义 |
| --- | --- |
| P0 | 阻断主流程，发布前必须通过 |
| P1 | 影响重要功能，发布前应通过 |
| P2 | 辅助能力或体验问题 |

## 登录与权限

| 编号 | 等级 | 场景 | 前置条件 | 步骤 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
| AUTH-001 | P0 | 获取验证码 | Redis 正常 | 打开登录页或请求 `/prod-api/auth/captcha` | 返回验证码图片/标识，页面显示验证码 |
| AUTH-002 | P0 | 正确登录 | 有有效账号 | 输入用户名、密码、验证码后登录 | 登录成功，进入看板 |
| AUTH-003 | P0 | 错误验证码 | 有有效账号 | 输入错误验证码登录 | 登录失败，提示验证码错误 |
| AUTH-004 | P0 | Token 过期 | 已登录 | 等待过期或使用过期 token 请求接口 | 返回未认证，前端跳转登录 |
| AUTH-005 | P1 | 按钮权限 | 不同角色 | 使用低权限账号访问新增/删除按钮 | 无权限按钮不可见或不可操作 |
| AUTH-006 | P1 | 强退在线用户 | 管理员账号 | 在线用户页强退指定用户 | 被强退用户后续请求失效 |
