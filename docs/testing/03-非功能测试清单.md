# 03 非功能测试清单

## 安全测试

- 未登录访问业务接口，应返回 401。
- 低权限账号访问高权限接口，应返回 403。
- 删除、修改接口必须校验权限。
- 前端隐藏按钮不能作为唯一权限控制。
- JWT 密钥少于 32 字节时应启动失败并提示明确。
- DeepSeek Key、数据库密码、Redis 密码不能出现在前端产物、日志和 Git 文档中。
- 文件上传限制类型和大小，避免上传脚本或超大文件。
- 图片访问路径不能暴露服务器敏感目录。

## 性能测试

建议最低压测目标：

| 场景 | 目标 |
| --- | --- |
| 登录 | P95 < 800ms |
| 列表查询 | P95 < 1s |
| 看板汇总 | P95 < 1.5s |
| 甘特图数据 | P95 < 2s |
| 图片质检 | 视模型大小而定，需记录基线 |
| 实时质检 WebSocket | 连续 10 分钟不断连 |

前端当前构建存在主包超过 500KB 的警告，应关注首屏加载性能。

## 兼容性测试

- Chrome 最新版。
- Edge 最新版。
- 1366x768、1920x1080、2K 分辨率。
- 浏览器缩放 90%、100%、125%。
- 甘特图、表格、下拉框在窄屏下不应遮挡关键操作。

## 稳定性测试

- Redis 重启后，验证码和会话应有合理失败提示。
- MySQL 短暂不可用时，后端不应产生不可恢复状态。
- DeepSeek API 超时或返回错误时，AI 页面不应白屏。
- ONNX 模型文件缺失时，应启动失败或在检测时返回明确错误。
- 图片结果目录不可写时，检测接口应返回明确错误。

## 数据一致性测试

- 删除订单前检查是否有关联批次、计划。
- 批次被计划占用后不应被重复排产。
- 计划状态变更后，工序计划状态不能出现矛盾。
- 质检失败创建异常时，异常应能关联到工序计划。
- 返工/关闭后，状态流转应可追溯。

## 可观测性检查

- 后端关键异常日志应包含业务 ID。
- DeepSeek 调用失败应记录原因，但不能打印完整 Key。
- 质检模型加载失败应打印模型路径。
- WebSocket 断连应能在日志中定位 sessionId。
- 部署文档应有健康检查和日志排查命令。
