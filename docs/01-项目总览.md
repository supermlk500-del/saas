# 01 项目总览

## 项目定位

织慧通是面向纺织生产场景的 SaaS 管理系统，核心覆盖订单、来料批次、工艺路线、生产排产、质量检测、异常闭环和系统权限。

可以把它理解为：

```text
订单需求 -> 批次资源 -> 工艺路线 -> 生产计划 -> 工序计划 -> 质检结果 -> 异常处理
```

## 当前核心能力

### 业务能力

- 订单管理：订单、订单明细、订单批次分配。
- 来料资源：来料批次、批次资源池、IQC 任务与结果。
- 工艺中心：工艺路线、工序、设备、工序设备能力。
- 排产管理：订单排产池、批次执行池、生产计划、工序计划、甘特图、AI 智能排产建议。
- 质量管理：实时质检、离线图片检测、质检结果、异常闭环、返工处理、CAPA、AI 质检分析。
- 系统管理：用户、角色、菜单、部门、岗位、在线用户。

### AI 能力

- 排产：规则/算法生成排产建议，DeepSeek 负责解释方案。
- 质检：浏览器 Web Worker 使用 ONNX Runtime Web 完成图片和视频帧检测，后端负责模型分发、结果校验和落库。
- 报告：DeepSeek 生成排产建议说明与质检分析报告。

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 前端 | Vue 3、TypeScript、Vite、Ant Design Vue、Pinia、Axios |
| 后端 | Spring Boot 3.3、Spring Security、MyBatis-Plus |
| 数据 | MySQL 8、Redis |
| AI/算法 | ONNX Runtime Web（WebGPU/WASM）、OR-Tools、DeepSeek API |
| 部署 | Docker/容器化部署，Nginx 代理前端和后端接口 |

docs/
