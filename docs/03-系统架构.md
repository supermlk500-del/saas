# 03 系统架构

## 总体结构

```text
浏览器
  ├── Vue 3 / Ant Design Vue
  └── Web Worker + ONNX Runtime Web（WebGPU/WASM）
  ▼
前端应用 frontend
  │ /prod-api 代理
  ▼
Spring Boot 后端 backend
  ├── Spring Security + JWT + Redis 会话
  ├── MyBatis-Plus
  ├── ONNX 模型受控分发与客户端结果校验
  ├── OR-Tools 排产优化
  ├── DeepSeek 结果解释
  └── 质检会话、证据文件与业务落库
  │
  ├── MySQL：业务数据
  ├── Redis：验证码、登录会话、在线状态
  └── 文件系统：上传图片、质检结果图、ONNX 模型
```

## 后端分层

```text
Controller -> Service -> Mapper -> MySQL
```

后端模块位于：

```text
backend/src/main/java/com/zhihuitong/modules
```

| 模块 | 说明 |
| --- | --- |
| `system` | 登录、用户、角色、菜单、部门、岗位、在线用户 |
| `order` | 订单、订单明细、订单批次关联、订单排产池 |
| `batch` | 来料批次、批次资源池 |
| `process` | 工艺路线、工序、设备、设备能力 |
| `plan` | 生产计划、工序计划、甘特图、重排 |
| `quality` | 质检任务、客户端结果校验、质检记录、检测附件、实时会话 |
| `exception` | 异常记录、关闭、返工 |
| `ai` | AI 排产建议、AI 质检分析、ONNX 模型契约/分发、DeepSeek 解释 |
| `dashboard` | 看板汇总 |

## 认证链路

1. 前端请求 `/prod-api/auth/captcha` 获取验证码。
2. 用户登录 `/prod-api/auth/login`。
3. 后端校验验证码、账号密码。
4. 生成 JWT 和 Redis 登录会话。
5. 前端保存 token。
6. 后续请求在 `Authorization: Bearer <token>` 中携带 token。
7. 后端 `JwtAuthenticationFilter` 解析 token、校验会话和权限。
