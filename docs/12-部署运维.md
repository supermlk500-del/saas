# 12 部署运维

## 部署目标

当前项目适合采用：

```text
前端容器 + 后端容器 + 宿主机 MySQL + Redis 容器/宿主机 Redis
```

生产环境建议将文件和模型挂载到宿主机持久化目录：

```text
/opt/saas/docs
/opt/saas/data
```

## 关键环境变量

### 后端

| 变量 | 示例 | 说明 |
| --- | --- | --- |
| `SPRING_PROFILES_ACTIVE` | `prod` | 生产环境配置 |
| `SERVER_PORT` | `8081` | 后端端口 |
| `MYSQL_HOST` | `host.docker.internal` | MySQL 地址 |
| `MYSQL_PORT` | `3306` | MySQL 端口 |
| `MYSQL_DATABASE` | `zhihuitong` | 数据库名 |
| `MYSQL_USERNAME` | `zhihuitong` | 数据库账号 |
| `MYSQL_PASSWORD` | 不写入 Git | 数据库密码 |
| `REDIS_HOST` | `saas-redis` | Redis 地址 |
| `REDIS_PORT` | `6379` | Redis 端口 |
| `REDIS_PASSWORD` | 不写入 Git | Redis 密码，可为空 |
| `JWT_SECRET` | 至少 32 字节 | JWT 密钥 |
| `DEEPSEEK_API_KEY` | 不写入 Git | DeepSeek Key |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | 模型名 |
| `AI_YOLO_MODEL_PATH` | `/app/docs/best.onnx` | ONNX 模型路径 |
| `INSPECTION_STORAGE_UPLOAD_ROOT` | `/app/data/upload` | 原图目录 |
| `INSPECTION_STORAGE_RESULT_ROOT` | `/app/data/results` | 结果图目录 |

## Redis 容器示例

无密码：

```bash
docker run -d \
  --name saas-redis \
  --restart always \
  -p 127.0.0.1:6379:6379 \
  redis:7-alpine
```

有密码：

```bash
docker run -d \
  --name saas-redis \
  --restart always \
  -p 127.0.0.1:6379:6379 \
  redis:7-alpine \
  redis-server --requirepass "你的Redis密码"
```

验证：

```bash
docker exec saas-redis redis-cli ping
docker exec saas-redis redis-cli -a "你的Redis密码" ping
```

## 数据库重建

删除服务器数据库前必须确认已有完整转储。

示例：

```bash
mysql -uroot -p -e "DROP DATABASE IF EXISTS zhihuitong;"
mysql -uroot -p -e "CREATE DATABASE zhihuitong DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -uroot -p zhihuitong < /opt/saas/docs/database/zhihuitong.sql
```

## 密钥管理建议

不要把以下内容写入 Git：

- MySQL 密码；
- Redis 密码；
- JWT_SECRET；
- DeepSeek API Key；
- 服务器公网 IP、证书私钥。

建议放在服务器 `.env` 或部署平台的 Secret 管理中。
